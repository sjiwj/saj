⚠️ 常见报错急救

新手 90% 的错误，都在这里

SyntaxError: invalid syntax（语法错误）
最常见的原因：用了中文标点。

Python 只认英文的 " ' ( ) : , =。

如果你用中文输入法打了 “” （） ： ，，就会报这个。

怎么查：看报错提示的行数，去那一行找中文标点，改成英文的。

防坑：写代码时，把输入法切到英文。

IndentationError: expected an indented block（缩进错误）
if / for / def 后面那行，要缩进（缩进 4 个空格）。 
if money > 100:
print("有钱")     # ❌ 报错：没有缩进

if money > 100:
    print("有钱")   # ✅ 对：缩进了 4 个空格

注意：同一段里，缩进要一致（都用 4 个空格，别有的用 Tab 有的用空格）。

NameError: name 'xxx' is not defined（名字没定义）
用了一个"没装东西的盒子"。 
print(money)     # ❌ 如果前面没写过 money = 100，就报这个

money = 100      # ✅ 先给盒子装东西
print(money)

怎么查：确认那个名字前面有没有赋值过；有没有拼错（大小写也算，Money 和 money 是两回事）。

FileNotFoundError（找不到文件）
要打开的文件，路径写错了，或者文件不在那儿。

怎么查：确认文件名拼对（含后缀 .txt / .md）；确认文件在那个文件夹里。

UnicodeDecodeError（编码错误 / 中文乱码）
读写中文文件时，没写 encoding="utf-8"。 
open("a.txt", "r", encoding="utf-8")   # ✅ 加上这个就不会乱码
报错怎么办（通用三步）
① 别慌——报错不是"你笨"，是程序在告诉你"哪里不对"。
② 看最后一行——Python 报错的最后一行最有用，会写明"什么错"。
③ 看行号——往上找 line 数字，去那一行检查。

第 0 课 · 先把 Python 装上

Windows / Mac / 手机 —— 三选一

先搞懂一件事
Python 是一个程序。你写的代码是"菜谱"，Python 是照着菜谱做菜的"厨师"。
所以第一步：先把"厨师"装到你的电脑上。

🪟 如果你用 Windows

① 下载：浏览器打开 python.org，点黄色的 Download Python 按钮。
② 安装（关键一步）：双击下载的安装包，在第一页最下面，务必勾上 Add Python to PATH（把 Python 加入环境变量）。然后点 Install Now。
⚠️ 最容易漏的一步
那个 Add Python to PATH 的勾，一定要勾！不勾的话，后面打命令会说"找不到 python"。
③ 验证：按 Win + R，输入 cmd 回车，打开黑窗口，输入 python --version 回车。
出现类似 Python 3.12.x 就成功了。

🍎 如果你用 Mac

① 打开"终端"：按 Command + 空格，输入 终端 或 Terminal，回车。
② 检查有没有：输入 python3 --version 回车。
如果有版本号 → 已装好，跳到验证。
如果提示没有 → 继续 ③。
③ 安装：浏览器打开 python.org，下载 macOS 版安装包，双击一路"下一步"。
④ 验证：终端里输入 python3 --version，出现版本号即成功。

📱 如果你只有手机/平板

手机不能直接装"电脑版 Python"，但可以用 App：

方式说明
Termux（安卓）去应用商店（或 F-Droid）装 Termux，打开后输入 pkg install python
部分平板自带 Linux如华为/荣耀的"Linux 实验室"，进去就有终端
在线 Python浏览器搜"在线 Python"，有网页版能在浏览器里直接跑（最省事，但功能有限）

✅ 最后验证：能跑第一个程序

① 建个文件夹（比如叫 python学习），进去。
② 建个文件：新建一个文本文件，改名叫 hello.py（.py 是 Python 文件后缀）。
③ 写一句：用记事本打开它，写 print("你好")，保存。
④ 运行：打开命令行（Windows 是 cmd，Mac 是终端），先 cd 到那个文件夹，再输入 python hello.py（Mac 用 python3 hello.py）。
屏幕出现 你好 → 恭喜，你跑通了第一个程序！
遇到问题？
去看最上面的 「常见报错急救」，90% 的装环境问题都在那。

第 1 课 · 让程序说话

print / 变量 / 运算 / 列表 / 循环

1. 打印（最基础）

print("你好，Python！")

人话：打印出括号里引号包着的内容。print 读成"打印"。

注意引号
必须用英文的双引号 "，不是中文的 “”。这是新手最常犯的错。
怎么运行 & 怎么改
运行：存成 lesson1.py，命令行里 python lesson1.py（Mac：python3）。
改：把引号里的字换成你想说的，比如 "今天天气不错"，再跑一次。

2. 变量（给东西起名字）

name = "小明"
age = 18

人话：把 "小明" 装进叫 name 的盒子；把 18 装进 age。

= 不是"相等"
= 是「把右边装进左边」。很多人卡在这。

3. 拼接（用 + 串起来）

print("你好，" + name + "！")   # → 你好，小明！

4. 运算（程序帮你算）

age = age + 1    # age 从 18 变成 19

人话：先算右边（18+1=19），再存回 age。自己是自己加点东西，叫"更新"。

5. 列表（一排东西）

fruits = ["苹果", "香蕉", "橘子"]

人话：[ ] 就是一排；每个东西用引号包住、逗号隔开。

6. 循环（对每个做一遍）★ 最重要的一个

for f in fruits:
    print("水果：", f)

人话：把 fruits 里的东西一个一个拿出来，每拿一个就叫它 f，然后做下面缩进的事。

手动跑一遍（这样看就懂了）
第1轮 f="苹果" → 打印「水果： 苹果」
第2轮 f="香蕉" → 打印「水果： 香蕉」
第3轮 f="橘子" → 打印「水果： 橘子」
第4轮 没了 → 循环结束
小测（看看你真懂没）
numbers = [1, 2, 3]
for n in numbers:
    print(n * 10)
会打印什么？
答案：10、20、30（每轮把当前那个数 ×10）
怎么运行 & 怎么改
把这段存成 lesson1.py 跑一遍。
练习：把 fruits 改成 ["猫", "狗"]，看是不是只打印两行。

第 2 课 · 让程序做判断

if 判断 / def 函数 / 计数器

1. 判断（如果…就…否则…）

score = 75

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

人话：从上往下判断，第一个成立的就走它下面那句，其余跳过。上面会打印"及格"。

别搞混
if = 如果；elif = 否则如果（再判一次）；else = 否则（都不成立）。
注意：if 那行末尾有个英文冒号 :，下面要缩进。
怎么运行 & 怎么改
存成 lesson2.py 跑。练习：把 score 改成 95，看输出是不是变"优秀"。

2. 函数（把一段活打包）

def add(a, b):
    return a + b

结果 = add(3, 5)
print(结果)    # → 8

人话：def = 定义（打个包、起个名）；return = 把结果交出来。以后随时喊 add(3, 5)，它就重算一遍。

3. 计数器（循环 + 判断 + 数字累加）

fruits = ["苹果", "香蕉", "橘子", "苹果"]
苹果数 = 0
for f in fruits:
    if f == "苹果":
        苹果数 = 苹果数 + 1
print("苹果有", 苹果数, "个")   # → 2

人话：先准备一个计数器（0）；挨个看，等于"苹果"就 +1。== 是"等于吗"（两个等号）。

= 和 == 别搞混
= 是"装进去"；== 是"等于吗"（用来判断）。

第 3 课 · 读写文件

字符串操作 / 写文件 / 读文件 / 数字符

1. 字符串操作（文字也能操作）

句子 = "我爱学习编程"
len(句子)          # 6  —— 数长度
句子[0:2]          # 我爱 —— 取前两个
句子[-2:]          # 编程 —— 取后两个
句子.split("学习") # ['我爱', '编程'] —— 切开
句子.replace("编程", "Python")   # 替换某些字
`[0:2]` 是啥
从第 0 个开始取，取到第 2 个（不含）。所以取到的是前 2 个字。

2. 写文件（把东西存下来）

with open("test.txt", "w", encoding="utf-8") as f:
    f.write("这是第一行\n这是第二行")

人话：打开文件用"写"模式（"w"），把内容写进去，用完自动关。\n 是"换行"。

注意
"w" 模式会覆盖原文件（清空重写）。encoding="utf-8" 保证中文不乱码。

3. 读文件（把东西读出来）

with open("test.txt", "r", encoding="utf-8") as f:
    内容 = f.read()
print(内容)

人话："r" = 读模式；f.read() 把全部内容读出来，装进"内容"。

4. 数汉字（实用！）

text = "我爱学习编程123"
汉字数 = 0
for c in text:
    if "\u4e00" <= c <= "\u9fff":
        汉字数 = 汉字数 + 1
print(汉字数)    # → 6（只数汉字，数字和字母不算）
`len()` 和 这段 的区别
len(text) = 数所有字符（汉字+数字+字母，这里是 9）
这段循环 = 只数汉字（这里是 6）
`\u4e00` 是什么
汉字的编码范围。"\u4e00" <= c <= "\u9fff" 就是"这个字是不是汉字"。

第 4 课 · 你的第一个小工具

把学过的零件，拼成一个"字数统计器"

完整代码

# 统计一个文件有多少汉字
print("=== 字数统计工具 ===")

文件名 = input("请输入文件名：")

with open(文件名, "r", encoding="utf-8") as f:
    内容 = f.read()

汉字数 = 0
for c in 内容:
    if "\u4e00" <= c <= "\u9fff":
        汉字数 = 汉字数 + 1

总字符数 = len(内容)

print("总字符数（含标点）：", 总字符数)
print("汉字数（纯字数）：", 汉字数)

新东西：input

文件名 = input("请输入文件名：")

人话：input = 程序停下来，显示问题，等你打字按回车，把你打的字装进盒子。

怎么运行（务必看这里）

① 准备一个测试文件：在同一个文件夹里，新建 test.txt，随便写几句话，保存。
② 把这个程序存成 counter.py。
③ 运行：命令行输入 python counter.py（Mac：python3）。
④ 它问你"请输入文件名" → 你输入 test.txt 回车。
⑤ 它就打印出你那个文件有多少汉字。
重点：这段"没有新东西"
它只是把学过的零件拼起来：print + input + for + if + len。
编程就是这么回事——零件拼起来，就成了工具。

怎么改（练习）

  • 把 "请输入文件名：" 改成别的提示语
  • 加一句判断：if 汉字数 >= 100: print("不错")
  • 多试几个文件，看结果对不对
