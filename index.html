第 1 课 · 让程序说话

print / 变量 / 运算 / 列表 / 循环

1. 打印（最基础）

print("你好，Python！")

人话：打印出括号里引号包着的内容。看代码时，把 print 读成"打印"就行。

2. 变量（给东西起名字）

name = "朋友"
money = 100

人话：把 "朋友" 装进叫 name 的盒子；把 100 装进 money。

关键
= 不是"相等"，是「把右边装进左边」。很多人卡在这。

3. 拼接（用 + 串起来）

print("你好，" + name + "！")   # → 你好，朋友！

4. 运算（程序帮你算）

money = money + 50    # money 从 100 变成 150

人话：先算右边（100+50=150），再存回 money。自己是自己加点东西，是"更新"。

5. 列表（一排东西）

skills = ["写小说", "学Python", "做副业"]

人话：[ ] 就是一排；每个东西用引号包住、逗号隔开。

6. 循环（对每个做一遍）★ 最重要的一个

for s in skills:
    print("  -", s)

人话：把 skills 里的东西一个一个拿出来，每拿一个就叫它 s，然后做下面缩进的事。

手动跑一遍（这样看就懂了）
第1轮 s="写小说" → 打印「- 写小说」
第2轮 s="学Python" → 打印「- 学Python」
第3轮 s="做副业" → 打印「- 做副业」
第4轮 没了 → 循环结束
小测（看看你真懂没）
numbers = [10, 20, 30]
for n in numbers:
    print(n * 2)
会打印什么？
答案：20、40、60（每轮把当前那个数 ×2）
为什么用循环
比"一行行写 print"强——不管那排有 3 个还是 300 个，都是这两行搞定。

第 2 课 · 让程序干活

判断 / 函数 / 统计

1. 判断（如果…就…否则…）

if money > 5000:
    print("有钱")
elif money > 1000:
    print("还行")
else:
    print("紧巴")

人话：从上往下判断，第一个成立的就走它下面那句，其余跳过。

别搞混
if = 如果；elif = 否则如果（再判一次）；else = 否则（都不成立）。

2. 函数（把一段活打包）

def 算工资(时薪, 小时数):
    总收入 = 时薪 * 小时数
    return 总收入

结果 = 算工资(50, 8)   # → 400

人话：def = 定义（打个包、起个名）；return = 把结果交出来。以后随时喊 算工资(50,8)，它就重跑一遍。

3. 统计（循环 + 判断 + 计数器）

学python天数 = 0
for 任务 in 本周计划:
    if "Python" in 任务:
        学python天数 = 学python天数 + 1

人话：先准备一个计数器（0）；挨个看任务，含"Python"就 +1。

第 3 课 · 读写文件

字符串操作 / 写文件 / 读文件 / 数汉字

1. 字符串操作（文字也能操作）

句子 = "长生从收录万法开始"
len(句子)          # 9  —— 数长度
句子[0:3]          # 长生从 —— 取前三个
句子[-3:]          # 法开始 —— 取后三个
句子.split("从")   # ['长生', '收录万法开始'] —— 切开
句子.replace("万法", "斩妖")   # 替换某些字
`[0:3]` 是啥
从第 0 个开始取，取到第 3 个（不含）。所以取到的是前 3 个字。

2. 写文件

with open("notes/xxx.txt", "w", encoding="utf-8") as f:
    f.write("要写的内容")

人话：打开文件用"写"模式（"w"），把内容写进去，用完自动关。encoding="utf-8" 是保证中文不乱码。

3. 读文件

with open("notes/xxx.txt", "r", encoding="utf-8") as f:
    内容 = f.read()

人话："r" = 读模式；f.read() 把全部内容读出来，装进"内容"。

4. 数汉字（实用！）

汉字数 = 0
for 字符 in 内容:
    if "\u4e00" <= 字符 <= "\u9fff":
        汉字数 = 汉字数 + 1
`len()` 和 这段 的区别
len(内容) = 数所有字符（汉字+标点）
这段循环 = 只数汉字（写小说统计字数要的是这个）
`\u4e00` 是什么
汉字的编码范围。"\u4e00" <= 字符 <= "\u9fff" 就是"这个字是不是汉字"。

第 4 课 · 你的第一个工具

把学过的零件，拼成一个"字数统计器"

完整代码

# -*- coding: utf-8 -*-
print("=== 字数统计工具 ===")

文件名 = input("请输入文件名：")

with open("notes/" + 文件名, "r", encoding="utf-8") as f:
    内容 = f.read()

汉字数 = 0
for 字符 in 内容:
    if "\u4e00" <= 字符 <= "\u9fff":
        汉字数 = 汉字数 + 1

总字符数 = len(内容)

print("文件：", 文件名)
print("总字符数（含标点）：", 总字符数)
print("汉字数（纯字数）：", 汉字数)

if 汉字数 >= 3000:
    print("达标")
else:
    print("还差", 3000 - 汉字数, "字")

新东西：input

文件名 = input("请输入文件名：")

人话：input = 程序停下来，显示问题，等你打字按回车，把你打的字装进盒子。

跑出来的样子
总字符数（含标点）：4252
汉字数（纯字数）：3472
达标

重点：这段"没有新东西"

它只是把学过的零件拼起来：print + input + for + if + len。
编程就是这么回事——零件拼起来，就成了工具。

+ - * /—加 减 乘 除
if伊夫如果

for佛对每一个
in因在…里面
len楞长度（数几个）

return瑞特恩交出结果
